# WeatherAI

Real-time weather dashboard with AI-powered summaries, built on the [WeatherAI API](https://weather-ai.co/docs).

## Live Demo

[https://weather-ai-ahsan.vercel.app](https://weather-ai-ahsan.vercel.app)

## Features

- **Auto location detection** — uses browser GPS; falls back to IP-based detection
- **AI summary** — natural-language weather insight generated by the API
- **Current conditions** — temperature, condition, humidity, wind speed/direction, feels like, UV index
- **Hourly forecast** — scrollable 24-hour chart with icons and rain probability
- **7-day forecast** — daily high/low, condition icons, rain chance
- **City search** — search any city worldwide via OpenStreetMap geocoding
- **Usage badge** — live request quota indicator in the navbar

## Upstream API Endpoints

| Endpoint | Purpose | Cache |
|---|---|---|
| `GET /v1/weather-geo?ip=` | Weather by IP with geo headers | none |
| `GET /v1/weather?lat=&lon=&days=7&ai=true` | Weather by coordinates | 10 min |
| `GET /v1/usage` | Request quota and plan info | none |

Geocoding uses [OpenStreetMap Nominatim](https://nominatim.org/) — cached for 24 hours.

## Local Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/ahsan360/weather-ai.git
   cd weather-ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create `.env.local`:
   ```
   WEATHER_API_KEY=wai_your_key_here
   ```
   Get your key at [weather-ai.co](https://weather-ai.co) → Dashboard → API Keys.

4. Start the dev server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000)

> **Security note:** `WEATHER_API_KEY` is read only inside Next.js Route Handlers — it is never sent to the browser.
